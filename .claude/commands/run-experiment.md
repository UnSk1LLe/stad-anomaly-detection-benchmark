## Состояние репозитория

Ветка и изменения: !`git status --short --branch`

Последние коммиты: !`git log --oneline -5`

Каталоги прогонов: !`ls reports`

## Задание

Запусти пайплайн эксперимента через агента `experiment-orchestrator` для цели:

$ARGUMENTS

Порядок обязателен:

1. Оркестратор уточняет цель прогона (сетка, сиды, устройство, какие решающие
   правила закрываются) — спрашивает, если из задания это не выводится.
2. `experiment-runner` — `make test`, затем прогон в фоне с логом.
3. `results-analyst` — R0, мощность, санитарные проверки, правила R1–R10,
   сравнение с прошлым прогоном; находки с классом A/B.
4. Правки класса A — `code-surgeon`, каждая с тестом, затем `make test` + `make smoke`.
5. Класс B — остановка и вопрос пользователю с вариантами и рекомендацией.
   Ничего не менять до ответа.
6. Итоговая сводка: вывод по каждой главе, что осталось открытым.
