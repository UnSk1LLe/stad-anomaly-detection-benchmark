## Рабочие приёмы и грабли

- Гейт `.claude/hooks/guard_protocol.py`: `ask` на протокольные файлы,
  `deny` на ручную правку `reports/` и `data/`. Результаты в `reports/` пишутся
  только скриптами. В фоновых агентах `ask` = отказ: им запрещать гейтовые пути,
  `git reset`, `rm -rf`.
- Для нескольких независимых задач класса A — `docs/workflows/implement_review_fix.js`
  (implement → два ревью → fix, worktree на задачу, затем squash по коммиту на
  задачу). Первой командой агента — `git checkout -b <ветка> <base>`: worktree
  может создаться не от текущей ветки.
- Временные worktree агентов исключать локально: `.claude/worktrees/` в
  `.git/info/exclude`. Оркестратору не делать `cd` в worktree агента.
- Состав коммита проверять `git ls-files` / `git diff --cached --stat` (правило 10).
